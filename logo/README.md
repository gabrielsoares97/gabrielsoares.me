# Gabriel Soares logo set

Two scalable SVG deliverables based on the approved brief:

- `gabriel-soares-icon.svg` — icon-only achievement badge.
- `gabriel-soares-lockup.svg` — horizontal lockup with `Gabriel Soares` and `dev independente`.

Both use a flat palette, thick indigo outlines, and a hard down-right shadow. The SVGs have no raster dependencies and remain editable in Figma, Illustrator, Inkscape, or a code editor.
